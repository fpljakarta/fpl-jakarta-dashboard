Team value

The richest squads

Every squad in the league, most valuable first. There is a prize on this one at the end of the season, so it is worth knowing where you stand.

01  Where everyone stands

Team value is the squad plus whatever is in the bank — the same number the game shows you, and the same one the end-of-season prize is settled on. The bank is listed separately because it is part of that total, not an addition to it.

Values move with player prices and settle at each deadline, so this page changes as the game reprices players rather than as matches are played. Everyone starts the season on £100.0m.
